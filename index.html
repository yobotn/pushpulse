PushPulse

The push heartbeat of your GitHub repos. Every count is shown, zeros included.

Public repos work right away. If a repo is private, PushPulse asks you for a token.

Want alerts with the tab closed? Fork this repo and turn on the hourly GitHub Action → ntfy.

Tokens and watched repos stay in this browser. PushPulse has no server and only talks to api.github.com.
